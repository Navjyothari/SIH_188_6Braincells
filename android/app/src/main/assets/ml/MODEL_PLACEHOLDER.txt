THIS IS A PLACEHOLDER.

The actual MobileFaceNet TFLite model file (mobilefacenet.tflite, ~1.9 MB)
must be placed here before building.

License: Apache 2.0
Source:  https://github.com/sirius-ai/MobileFaceNet_TF
         (export the .pb checkpoint to TFLite using tf.lite.TFLiteConverter)

Alternatively, use the pre-exported TFLite from:
  https://github.com/shicai/MobileNet-Caffe (check for Apache 2.0 tag)

Steps to obtain:
  1. Clone the MobileFaceNet_TF repo (Apache 2.0 licensed).
  2. Download the pre-trained checkpoint.
  3. Run: python export_tflite.py --checkpoint_path <ckpt> --output mobilefacenet.tflite
  4. Copy the output here: android/app/src/main/assets/ml/mobilefacenet.tflite

The model MUST be placed in this directory before running `./gradlew assembleDebug`.
The build.gradle's aaptOptions { noCompress "tflite" } keeps it uncompressed for mmap.
